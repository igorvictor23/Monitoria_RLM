1. Proposições Simples

O que é uma proposição?

Proposição (ou sentença lógica) é toda frase que expressa um pensamento completo e à qual podemos atribuir um valor de verdadeiro (V) ou falso (F) — nunca os dois ao mesmo tempo, nem nenhum dos dois.

Para ser uma proposição, a frase precisa:

  1. Ter estrutura de oração (sujeito + predicado + verbo);
  2. Ser declarativa/afirmativa — nunca imperativa, interrogativa ou exclamativa;
  3. Obedecer a três princípios da lógica (ver abaixo).

Terceiro excluído

Toda proposição é verdadeira ou falsa, nunca existe uma terceira opção.

Não contradição

Uma proposição não pode ser verdadeira e falsa ao mesmo tempo.

Identidade

Uma proposição verdadeira é sempre verdadeira; uma falsa é sempre falsa.

Lógica bivalente

Como cada proposição só pode assumir um entre dois valores possíveis, dizemos que a lógica proposicional é bivalente.

Exemplos

São proposições

  • "O número 10 é par." — verdadeira V
  • "Todo quadrado é um retângulo." — verdadeira V
  • "A Lua é maior que a Terra." — falsa F
  • "Recife é a capital do Rio de Janeiro." — falsa F

NÃO são proposições

  • "Que dia lindo!" — exclamativa
  • "Você já almoçou?" — interrogativa
  • "Feche a porta." — imperativa

Proposição simples (ou atômica)

Proposição simples é aquela que não contém nenhuma outra proposição dentro dela — é uma sentença "de uma peça só", sem conectivos ligando outras sentenças.

  • Representamos proposições simples por letras minúsculas: p, q, r, s, …
  • O valor lógico de uma proposição simples p é indicado por V(p).
  • Por isso, proposições simples também são chamadas de variáveis proposicionais.
Exemplo

p: "O gato dormiu o dia todo."

Essa frase é declarativa, tem valor V ou F, e não é formada pela junção de outras proposições — logo, é uma proposição simples.

Por que isso importa

Toda proposição composta (próximo tópico) é construída a partir de proposições simples unidas por conectivos lógicos. Entender proposição simples é a base para tudo que vem depois: conectivos, tradução para linguagem simbólica e tabelas-verdade.

2. Proposições Compostas

Definição

Proposição composta (ou molecular) é aquela formada pela combinação de duas ou mais proposições simples, ligadas por palavras de conexão.

  • Representamos proposições compostas por letras maiúsculas: P, Q, R, S, …
  • Quando queremos deixar explícito quais proposições simples formam a composta, escrevemos:

    P(p₁, p₂, …, pₙ)

    para indicar que a proposição composta P é formada pelas n proposições simples p₁, p₂, …, pₙ.
  • Proposições compostas também são chamadas de fórmulas proposicionais (ou apenas fórmulas).

O que conecta as proposições simples?

Toda proposição composta existe porque duas ou mais proposições simples foram unidas por conectivos lógicos (ex: "e", "ou", "se… então"). É exatamente a presença de um conectivo que transforma uma proposição em composta — sem conectivo, ela continua simples.

Exemplo

Q: "Ana estuda de manhã e trabalha à tarde."

Aqui temos duas ideias simples ligadas pela palavra "e":

p: "Ana estuda de manhã."
q: "Ana trabalha à tarde."

Como Q é formada pela junção de p e q através de um conectivo, Q é uma proposição composta: Q(p, q).

Simples vs. Composta — resumo comparativo

Proposição SimplesProposição Composta
Notaçãoletras minúsculas (p, q, r…)letras maiúsculas (P, Q, R…)
Contém outra proposição dentro?NãoSim (duas ou mais)
Precisa de conectivo?NãoSim, sempre
Exemplop: "Choveu hoje."P: "Choveu hoje e o jogo foi cancelado."
Dica para identificar em provas

Se a frase tem uma palavra como e, ou, se…então, se e somente se ou começa com não ligando/alterando outra ideia, ela é composta. Se é uma única afirmação isolada, é simples.

3. Conectivos Lógicos

O que são

Conectivos lógicos (também chamados de operadores lógicos) são as palavras que ligam proposições simples para formar proposições compostas. É a partir deles que se define se o resultado da combinação será verdadeiro ou falso.

Na lógica matemática, cada conectivo tem uma palavra-chave da linguagem natural e um símbolo correspondente na linguagem simbólica.

Tabela dos conectivos

Conectivo (linguagem natural)SímboloNome da operação
e∧Conjunção
ou∨Disjunção (inclusiva)
ou … ou⊻Disjunção exclusiva
se …, então→Condicional
se, e somente se,↔Bicondicional
não∼Negação

O que cada um significa

∧
Conjunção

"p e q". Liga duas ideias que precisam ser ambas verdadeiras para que o todo seja verdadeiro.
Ex.: "Marcos é aluno e Marcos é atleta."

∨
Disjunção inclusiva

"p ou q". Basta que pelo menos uma das duas seja verdadeira para o todo ser verdadeiro (podem ser as duas).
Ex.: "Marcos é aluno ou Marcos é atleta."

⊻
Disjunção exclusiva

"ou p ou q". Exatamente uma das duas, nunca as duas ao mesmo tempo e nunca nenhuma.
Ex.: "Ou Marcos nasceu em janeiro ou nasceu em fevereiro."

→
Condicional

"se p, então q". Estabelece uma relação em que p é condição suficiente para q, e q é condição necessária para p.
Ex.: "Se chover, então a rua fica molhada."

↔
Bicondicional

"p se, e somente se, q". As duas proposições têm o mesmo valor lógico sempre — é como uma "via de mão dupla" entre duas condicionais.
Ex.: "Um número é par se, e somente se, é divisível por 2."

∼
Negação

"não p". Inverte o valor lógico de uma proposição (não cria uma proposição composta no sentido de "juntar duas sentenças", mas é tratada como conectivo por alterar o valor lógico da proposição original).
Ex.: "Não choveu hoje."

Observação importante

Algumas bancas de concurso e provas usam palavras alternativas para os mesmos conectivos. Fique atento a sinônimos como mas, todavia, contudo, no entanto, apesar de — todas essas palavras, no sentido lógico, costumam funcionar como uma conjunção (∧).

E os valores V/F?

O valor exato de cada conectivo (quando cada um dá verdadeiro ou falso) é detalhado no tópico Tabelas-Verdade.

4. Linguagem Natural ↔ Linguagem Simbólica

Por que isso é importante

Questões de raciocínio lógico raramente aparecem já em símbolos — normalmente vêm como uma frase em português, e é preciso "traduzir" para símbolos (p, q, ∧, ∨, →…) antes de resolver. Depois, muitas vezes é preciso fazer o caminho inverso: interpretar uma fórmula simbólica em português. Dominar essa via de mão dupla é essencial antes de montar tabelas-verdade.

Método para traduzir de natural → simbólica

  1. Identifique as proposições simples dentro da frase (cada ideia isolada, com valor V/F).
  2. Atribua uma letra minúscula para cada uma (p, q, r…).
  3. Identifique o conectivo que liga as ideias (e, ou, se…então, se e somente se, não).
  4. Monte a fórmula substituindo as ideias pelas letras e o conectivo pelo símbolo.

Exemplos: natural → simbólica

Conjunção (e → ∧)

"Bianca fala inglês e fala espanhol."

p: Bianca fala inglês.
q: Bianca fala espanhol.
Fórmula: p ∧ q
Disjunção inclusiva (ou → ∨)

"O prêmio será dinheiro ou será uma viagem."

p: O prêmio será dinheiro.
q: O prêmio será uma viagem.
Fórmula: p ∨ q
Disjunção exclusiva (ou…ou → ⊻)

"Ou você estuda de manhã ou você estuda à noite." (as duas opções se excluem)

p: Você estuda de manhã.
q: Você estuda à noite.
Fórmula: p ⊻ q
Condicional (se…então → →)

"Se o carro está sem combustível, então ele não liga."

p: O carro está sem combustível.
q: Ele não liga.
Fórmula: p → q

A condicional também pode aparecer disfarçada, sem a palavra "se" no início:

  • "q, se p" → p → q
  • "Quando p, q" → p → q
Bicondicional (se e somente se → ↔)

"Um triângulo é equilátero se, e somente se, seus três lados são iguais."

p: O triângulo é equilátero.
q: Seus três lados são iguais.
Fórmula: p ↔ q
Negação (não → ∼)

"O time não venceu a partida."

p: O time venceu a partida.
Fórmula: ∼p

Exemplos: simbólica → natural

Fazendo o caminho inverso, atribuindo:

  • p: "Júlia estuda música."
  • q: "Júlia toca piano."
FórmulaLeitura em linguagem natural
p ∧ qJúlia estuda música e toca piano.
p ∨ qJúlia estuda música ou toca piano.
p ⊻ qOu Júlia estuda música ou toca piano (não as duas).
p → qSe Júlia estuda música, então ela toca piano.
p ↔ qJúlia estuda música se, e somente se, toca piano.
∼pJúlia não estuda música.
Pegadinhas comuns
  • "ou" nem sempre é inclusivo. Se as opções da frase se excluem naturalmente (ex.: "Rosa nasceu na Itália ou nasceu no Brasil" — ninguém nasce em dois lugares), trate como disjunção exclusiva (⊻), mesmo que a frase só use a palavra "ou".
  • Condição necessária vs. suficiente, na condicional p → q: p é condição suficiente para q; q é condição necessária para p.
  • Sinônimos de conjunção: mas, todavia, contudo, no entanto, apesar de → todos viram ∧.
  • Sinônimos de negação: "não é verdade que…", "é falso que…" → também viram ∼.

5. Tabelas-Verdade

O que é

Uma tabela-verdade é um dispositivo que lista todas as combinações possíveis de valores lógicos (V ou F) das proposições simples que compõem uma proposição composta, e o valor lógico resultante da composta em cada combinação.

Ela existe por causa do princípio do terceiro excluído: cada proposição simples só pode ser V ou F — então dá para listar exaustivamente todas as combinações possíveis.

Quantas linhas a tabela tem?

Teorema: a tabela-verdade de uma proposição composta com n proposições simples contém 2ⁿ linhas.

Ordem de precedência dos conectivos

Quando a proposição composta não tem parênteses, resolva na seguinte ordem:

  1. ∼ (negação)
  2. ∧ ou ∨ (conjunção/disjunção)
  3. → (condicional)
  4. ↔ (bicondicional)

Se houver parênteses, colchetes ou chaves, resolva sempre de dentro para fora.

Construa a tabela-verdade de: P(p, q, r) = (p ∧ ∼r) → q

Passo 1 — contar proposições simples: temos p, q, r → n = 3 → 2³ = 8 linhas.
